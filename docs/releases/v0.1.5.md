# v0.1.5 — 2026-11-14
Tagged on `main` after `dev → main`.

## Features
- the description file can be JSON (`"video_poster": 1`): the same content as the Markdown structure, for tools that generate it; read word for word, with no AI rewriting
- giving the description file alone fills the form (videos, SRT, thumbnails, platforms, language); a folder with several description files shows a hint naming the other one

Evidence: CI green (39 tests); a JSON written by a script went through `parse_post.py`, `scan.py` and `prepare.py` with no problems and gave the expected text for five uploads. Not tested: a real posting run from a JSON file.
