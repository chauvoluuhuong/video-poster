# v0.1.8 — 2026-11-25
Tagged on `main` after `dev → main`.

## Features
- View button on the Files screen: each Video and Cover row opens the chosen file in a window over the page — the video plays with controls, the cover shows as an image. Esc, Close or a click outside closes it. Greyed out until a path is filled in; a missing file or a format the browser cannot play shows a short message.

Evidence: CI green (46 tests, new `test_view_file` covers the file route: types, Range, 404, token); checked in a browser with a sample 16:9 video and cover.
Not tested: `.mov`/`.mkv` files in browsers other than Chrome.
Rollback: revert on `dev`, release a patch.
