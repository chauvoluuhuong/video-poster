# v0.1.7 — 2026-11-23
Tagged on `main` after `dev → main`.

## Features
- translations in the description file: subtitles in more languages per video (`- Wide SRT en: file.en.srt`, or `files.wide.translations` in JSON) and a translated title and description (`## Translation en`, or `translations` in JSON)
- each upload gets only what its platform takes: YouTube (video and Short) adds every subtitle language and the translated title and description; Facebook Page videos add each subtitle file named `name.<locale>.srt`; Reels, LinkedIn and TikTok skip them, and the Check screen says so

Evidence: CI green (45 tests); the Check screen checked in a browser with a Vietnamese post plus English subtitles and title on six uploads. Not tested: adding the extra languages on the real YouTube and Facebook pages.
Rollback: revert on `dev`, release a patch.
