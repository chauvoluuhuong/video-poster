# v0.1.6 — 2026-11-17
Tagged on `main` after `dev → main`.

## Features
- choose whether a video is labelled as AI-generated: a "Made with AI" switch on the Files screen, shown and changeable per upload on the Check screen; uploaders set YouTube's "altered or synthetic content", TikTok's "AI-generated content" and Facebook's AI label from it instead of asking (LinkedIn has none: posted without, and noted)
- the description file can set it: `- AI label: yes` under `## Settings`, or `"settings": {"ai_label": true}` in JSON
- the switch starts off for every video; it is never carried over from the last run

Evidence: CI green (42 tests); the Files and Check screens checked in a browser (tick on the form → all uploads labelled, untick TikTok on the Check screen → `final.json` has TikTok off, the rest on). Not tested: setting the switch on the real upload pages.
Rollback: revert on `dev`, release a patch.
